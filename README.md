# StockSense C — Restaurant Inventory Management

StockSense is a simple restaurant inventory management project written in C. It helps track restaurant stock and manage inventory records.

## Features
- Add and view inventory items
- Organize items by name, category and unit
- Track current quantity and minimum stock level
- Identify items that need restocking
- Store inventory records in a text file

## Technologies
- C programming
- Structures and arrays
- File handling
- Text-file data storage

## Project Purpose
This project was built as a practical way to apply C programming concepts to a real-world restaurant inventory problem.

## How to Run
Compile `main.c` using a C compiler such as GCC:

```bash
gcc main.c -o stocksense
```

Run the compiled program:

```bash
./stocksense
```

On Windows, run:

```bash
stocksense.exe
```
